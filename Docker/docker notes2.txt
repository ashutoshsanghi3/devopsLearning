How Docker Builds an Image Step by Step From DockerFile:-
✔️ Docker does not create a "hidden" or "internal" container permanently, but rather, it temporarily spins up a container for each RUN instruction to execute the command, then commits the result as a new layer in the image, not inside a persistent container.
✔️ COPY and ADD do not run in a container but just modify the image's filesystem.
✔️ Each command in a Dockerfile adds a new layer to the image.

image layered caching 

Docker Layered Caching: How It Works 

Docker uses layered caching to speed up image builds and avoid unnecessary re-execution of commands. Each instruction in a Dockerfile creates a layer, and if a layer hasn't changed, Docker reuses the cached version instead of rebuilding it.
