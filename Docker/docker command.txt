-Docker images use a layered file system where each layer is immutable.
-Containers create a writable layer on top of the base image.
-If a file is modified in a container, Copy-on-Write (CoW) ensures that:
-The system first checks if the file exists in the writable layer.
-If not, it checks lower layers until the file is found.
-A copy of the file is then placed in the writable layer, where modifications occur.

writable layer stores any changes made during the container's execution, such as:

Files created or modified
Installed packages
Configuration changes

dangling/orphaned container

when we create container it refers to image but when we stop it ,it refers to both image and writable layer
